#  FactuPro

**Application Android de facturation pour travailleurs autonomes au Québec**

FactuPro est une application mobile Android développée pour simplifier la création et la gestion des factures des travailleurs autonomes.

##  Fonctionnalités

- 👤 Création et gestion des clients
- 🧾 Création de factures
- 💰 Calcul automatique de la TPS et de la TVQ
- 📄 Génération de factures en PDF
- 💾 Sauvegarde locale des données
- 🔐 Inscription et connexion utilisateur
- 📱 Interface simple et adaptée aux appareils Android

##  Technologies utilisées

- Kotlin
- Android Studio
- XML
- MVVM
- Room / SQLite
- Git & GitHub

##  Architecture

L'application utilise l'architecture **MVVM (Model-View-ViewModel)** afin de séparer l'interface utilisateur, la logique métier et la gestion des données.
